# Grow Research

**Status:** Available  
**Primary users:** Growth, content, and search teams beginning a structured research workflow

## Purpose

Grow Research turns a company website or domain into a guided research run that can feed later planning. It provides a resumable workflow instead of requiring teams to assemble market and search context manually before using Grow.

## Capabilities

- Begin with a website or domain.
- Follow a guided setup flow for a research run.
- Keep research scoped to the active workspace.
- View progress while the run is active.
- Resume an existing run by its run identifier.
- Complete connection steps required by the research workflow.
- Move resulting opportunities or context into the Grow Search plan.
- Use onboarding guidance when the account has not completed prerequisite setup.

## How it works

1. The user enters or confirms the business website/domain and the workspace context.
2. Episode creates a research run and gathers the supported information in stages.
3. If a source connection is needed, the flow pauses at a clear connection step rather than silently omitting that source.
4. The user can leave and later return to the same run.
5. Completed findings provide context for planning work and can hand off into Grow Search.

## Important behavior

A research run is workspace-specific. Users working across brands should confirm the active workspace and domain before starting so findings do not enter the wrong planning context.

Research output should be treated as a structured starting point. Source availability, site crawlability, connected-data permissions, and changing search conditions affect completeness. The workflow’s handoff to a plan is a deliberate step; research findings do not automatically become committed work.
