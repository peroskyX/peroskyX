# Grow Search overview

**Status:** Available; the usefulness of metrics depends on connected sources and collected data  
**Primary users:** Organic-growth and content leads

## Purpose

The Search overview translates search and AI-discovery data into an operational summary. It combines performance indicators, work requiring attention, achieved results, upcoming work, goals, trends, and recommendations.

## Capabilities

- Show headline indicators such as non-brand clicks and AI mentions when data is available.
- Present priorities and items that need attention.
- Summarize recent results and what is coming up.
- Display goals and trend context.
- Offer recommendations based on the available search workspace data.
- Open a recommendation for more detail.
- Use **Fix with Episode** to hand an actionable issue to the product workflow.
- Add an opportunity to the plan or mark it for a team to handle.
- Explain missing source connections or permissions to administrators.

## How it works

Connected search sources and Episode activity provide the overview’s evidence. The page groups that information into decision-oriented sections rather than only presenting raw charts. A user can inspect an issue, choose whether Episode or their team should address it, and place planned work into the Search plan.

When a data source is absent or the viewer cannot connect it, the overview communicates the gap and uses account permissions to determine who can resolve it.

## Interpretation

Non-brand performance separates discovery demand from searches already containing the brand name. AI mentions describe visibility in the supported AI-answer monitoring context; they should not be assumed to represent every model or every user query.

Recommendations are prioritization support. A user should confirm strategic fit, factual accuracy, and available resources before committing work. Changes in search performance can lag publication and can be affected by factors outside Episode.
