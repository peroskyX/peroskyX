# Grow Search plan

**Status:** Available  
**Primary users:** Content leads, SEO operators, and teams coordinating growth work

## Purpose

The Search plan turns opportunities into managed work. It provides table and board views, lifecycle groupings, detailed item context, drafting, scheduling, and bulk operations so recommendations do not remain an unprioritized list.

## Capabilities

- Switch between table and board layouts.
- Search and filter plan items.
- Organize work into states such as suggested, needs attention, coming up, and published.
- Open an item detail panel without losing the plan context.
- Select several items and apply supported bulk actions.
- Draft content associated with a plan item.
- Preview a draft before advancing it.
- Schedule work or publication where the item workflow supports it.
- Discard unwanted suggestions or drafts through explicit actions.
- Hand work between Episode-assisted and team-owned paths.

## How it works

1. Opportunities enter the plan from research, overview recommendations, or user action.
2. The team filters and prioritizes items, then assigns an appropriate lifecycle state.
3. Opening an item reveals the underlying opportunity, supporting context, and available next actions.
4. Draft work can be created and previewed within the plan workflow.
5. Scheduled or completed items advance, while published results feed later reporting.

## Important behavior

Board columns communicate workflow state rather than independent copies of an item. Bulk actions should be used carefully because they can change several commitments at once. Discard is different from completion: it records that the team is not pursuing the item rather than claiming the result was delivered.

A scheduled item can still depend on author approval, destination configuration, or external CMS availability. The plan coordinates work; it does not remove those publishing safeguards.
