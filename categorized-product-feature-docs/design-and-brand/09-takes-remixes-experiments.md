# Takes, remixes, and experiments

**Status:** Takes and remixes are available; traffic-split A/B testing is available on the Scale plan  
**Primary users:** Growth teams, marketers, and designers comparing page directions

## Purpose

A Take is an alternate version of a page. It lets a team explore a different treatment without losing the current version, then optionally test that treatment against the live page and promote the winner.

## Capabilities

- Create an alternate version beside the original page.
- Remix an existing page manually or brief AI to produce the variation.
- Preserve the original while the Take is edited and reviewed.
- Compare creative directions before deciding which should become primary.
- On eligible plans, split traffic between the live page and a Take.
- Read experiment results and promote a winning Take into the live page.

## How it works

1. The user creates a Take from a page, preserving the current version as the baseline.
2. They change the Take directly in Studio or describe a new direction to the agent.
3. The team reviews both versions. A Take can be used simply as a creative branch; it does not have to become an experiment.
4. On Scale, an eligible Take can be placed into an A/B test with traffic divided between variants.
5. Results are reviewed in the optimization/analytics experience, and the preferred version can be promoted.

## Important behavior

Creating a Take does not change the live page. Starting an experiment is a separate action with plan and publication requirements. Promoting a winner is consequential because it replaces the primary page treatment; teams should check content, tracking, forms, and responsive behavior first.

Experiment results need enough traffic to be meaningful. The presence of a numerical leader should not be treated as certainty when the sample is small.
