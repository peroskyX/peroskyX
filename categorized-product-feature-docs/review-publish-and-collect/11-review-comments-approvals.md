# Review, comments, and approvals

**Status:** Available  
**Primary users:** Creators, stakeholders, clients, and approvers

## Purpose

Episode keeps review attached to the page being reviewed. Stakeholders can open a review link, comment on the relevant part of the page, and communicate approval without relying on screenshots or long email threads.

## Capabilities

- Share a review link with someone who does not have an Episode account.
- Protect a review link with an access code when extra control is needed.
- Pin a comment to the specific part of the page it concerns.
- Resolve ambiguity about which headline, image, or section feedback refers to.
- Record approvals and identify who approved.
- Show when content has changed after approval and the approval is stale.
- Keep the review workflow separate from public publishing.

## How it works

1. A creator prepares the page and generates or shares its review access.
2. The reviewer opens the link and enters an access code if one is configured.
3. They select the relevant page location, add a pinned comment, or provide approval.
4. The creator addresses feedback in Studio or through the agent.
5. If approved content changes, the approval state can be marked stale so an old decision is not mistaken for sign-off on new work.

## Important behavior

A review link is not the same as a published URL. It exists to support controlled feedback on work in progress. Accountless access makes external review easier, but the creator remains responsible for choosing an appropriate access code and deciding who receives the link.

Pinned feedback depends on the page structure that existed when it was added. Significant restructuring can make older context less obvious, which is why resolution and fresh approval matter after large revisions.
