# Blog appearance, authors, and address

**Status:** Available  
**Primary users:** Content administrators and brand owners

## Purpose

Blog settings define the shared experience around individual articles: where the blog lives, how it looks, who can be credited, and which elements frame the content.

## Capabilities

- Complete an initial blog setup flow.
- Configure the blog address and relevant route/path behavior.
- Adjust shared visual appearance through the blog look/editor surface.
- Configure header and footer presentation.
- Manage the list of article authors.
- Set publishing-role behavior represented by blog settings.
- Preview blog appearance with a representative thumbnail or editing surface.
- Archive a blog through the guarded archive flow.

## How it works

1. An authorized user completes setup and chooses the blog’s address context.
2. They establish shared visual choices, header/footer content, and authors.
3. Article editors then select from those shared authors and inherit relevant site presentation.
4. Changes to shared design affect the blog experience rather than the body content of one article.
5. If the blog is no longer needed, the archive workflow requires an explicit destructive decision.

## Important behavior

Blog configuration and article content are separate. Editing a header does not rewrite every article, and editing an article should not be used to simulate shared navigation. Address changes can affect existing links and should be coordinated with destination and SEO decisions.

Archiving is materially different from unpublishing one post. The interface uses a dedicated archive group so administrators can understand the wider impact before proceeding.
